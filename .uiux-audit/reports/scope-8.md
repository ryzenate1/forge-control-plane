## Scope-level patterns

1. **Unknown is rendered as zero, six times over, in the slice where a zero is most dangerous.** Backups KPI `|| 0` (`app/admin/backups/page.tsx:461-486`), artifact `formatBytes(0)` → "0 Bytes" (`:38-39,660`), engines `formatBytes(!bytes)` → "0 Bytes" (`app/admin/backups/engines/page.tsx:44-50,521`), Restic `dataFiles` 0 (`:522`), Migrations `(0)` in headings while loading (`components/admin/AdminMigrations.tsx:284,324`), docker `total ?? 0` stored (`components/admin/docker-events-feed.tsx:310`). Every one of them has a correct primitive available and unused: `ForgeMetric`/`AdminStatCard` renders `—` for an absent reading (`admin-ui.tsx:643-659`), and `lib/utils.ts:8-16` already returns `"Unavailable"` for a non-finite/negative size while `formatDate` (`lib/utils.ts:19-23`) returns `"Never"`/`"Unknown"` — the two backup files each re-implement a worse local copy (`app/admin/backups/page.tsx:38-49`, `app/admin/backups/engines/page.tsx:44-52`). In-repo precedent for the honest branch: `components/database/database-services-view.tsx:606` renders `{b.sizeBytes ? formatBytes(b.sizeBytes) : "—"}`.
2. **Failure is rendered as empty.** Cron Jobs (`app/admin/cron-jobs/page.tsx:340,381-385`) and Cron execution history (`:256,276`) never read `isError`; the Backups page reads it but only shows it on the Overview tab (`:318,452`). One shared `useResourceList`-style helper that returns `{loading, error, empty}` and the canonical trio (`AdminLoadingRows`/`AdminErrorState`/`EmptyState`) fixes all six pages.
3. **Not one page in the slice reports freshness, and two pages actively claim liveness they did not measure** (Docker Events `live 5s` + green dot during an error; Install streaming `Connected` before a handshake). The fix is already written: `<FreshnessBadge state={sourceState(query, interval)} />` in the `status` slot of `SectionHeader` (`admin-ui.tsx:146-157`, used at `AdminActivityLog.tsx:268`, `AdminMonitoring.tsx:387`, `AdminCleanup.tsx:58`).
4. **Three mutually incompatible status-tone systems in one group.** (a) local colour-word maps defaulting to "in flight" (`AdminOperations.tsx` post-edit consumer of (b), `AdminMigrations.tsx:38`, `app/admin/backups/page.tsx:51-73`, `app/admin/backups/engines/page.tsx:54`), (b) the central `deploymentStatusTone`/`statusTone` that resolves to `unknown` (`lib/api/status.ts:244-262`), (c) hand-written per-status Tailwind literals inside table cells (`docker-events-feed.tsx:56-107`, `AdminOperations.tsx:355`). `lib/api/status.ts:23` already names AdminOperations and AdminMigrations as files that were supposed to stop doing (a); `cancelled` is red under (a) and neutral under (b).
