### [F-01] FORGE-LOGIC-S01 — Subuser `*` escalation (P0, privesc)

**Severity:** **P0 — Privilege escalation / confidentiality+integrity break**
**Reference:** `pterodactyl-panel/app/Models/Permission.php:120` + `GetUserPermissionsService.php:18` + `SubuserController.php:154`
**Forge:** `store/permissions.go:89` (catalog), `store_users.go:306` `UpsertServerSubuser`, `544` `normalizeSubuserPermissions:564`, `permissions.go:206` `HasPermission`

`normalizeSubuserPermissions` builds `allowed = map[defaultSubuserPermissions()]` then `if permission=="" || seen[permission] || (!allowed[permission] && permission != "*") continue` — explicitly **exempts** `"*"` from allowlist. `HasPermission` treats `*` as universal grant. `UpsertServerSubuser` never loads actor's effective permissions; handler `handlers_servers.go:541` only checks `requireServerPermission(PermUserCreate)` (or `PermUserUpdate` for PATCH), not subset. Comment at `permissions.go:196` says "callers must ensure wildcard is only ever assigned to server owners or admins" — **no caller enforces it**.

Repro:
1. owner creates alice with `permissions=["user.create","file.read"]`
2. alice `POST /servers/:id/users {"email":"bob@example.com","permissions":["*"]}` → 200 (only `user.create` checked)
3. bob `GET /servers/:id/startup` sees `envVars` unredacted (needs `server:read-env` via `*`), `POST /servers/:id/schedules`, `database.view_password`, `buildpack.manage` etc.

Impact: any `user.create` holder = full control, including `cron.create` dispatching to node (still server-scoped but node-touching). Breaks subuser trust boundary; Pterodactyl never stores `*` for subusers — always computed.

Fix: `UpsertServerSubuser(ctx, serverID string, req UpsertServerSubuserRequest, actorID string, actorRole string)` → load `GetServerSubuser(ctx, serverID, actorID)` or `["*"]` for owner/admin, then `for _, p := range req.Permissions { if !HasPermission(actorPerms, p) && !actorIsOwnerOrAdmin { return fmt.Errorf("cannot grant %q",p) } }`; reject `*` unless `actorIsOwnerOrAdmin`; remove `permission=="*"` from subuser allow path or gate.

Status: **persists** from phase-02 F-01 through final-parity S02.

### [F-04] FORGE-LOGIC-S05 — CSP `fallback-nonce` + `strict-dynamic` (P1, defense-in-depth bypass)

**Severity:** **P1 — Deterministic nonce with `strict-dynamic` executes injected scripts**
**Reference:** Traefik CSP verbatim (no nonce fallback); Caddy CSP opt-in
**Forge:** `http/middleware_security.go:19` `generateNonce:22` `return "fallback-nonce"` + `27` CSP `script-src 'self' 'nonce-{nonce}' 'strict-dynamic'` + `43` `X-CSP-Nonce`; `middleware_security_headers.go:40` `generateMiddlewareNonce:43` same
