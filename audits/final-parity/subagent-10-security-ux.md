## 1. Executive Summary

Security and UX are inseparable at the control-plane seam: every RBAC/tenancy gap has a visible IA symptom, and every IA scatter has a security-widening effect. This audit re-verifies the cross-cutting finding of phases 01–05:

* **RBAC/tenancy is a strict superset of Pterodactyl + Portainer** — 40+ granular permissions vs Pterodactyl's ~45, plus org/project/env hierarchy vs Portainer's `ResourceControl` — **except** for three load-bearing gaps: (1) `*` wildcard persistable by any `user.create` holder without subset check (`store_users.go:297`), (2) mount allowlist too narrow (`store_mounts_ext.go:323` only blocks `/etc/forge` + `/var/lib/forge/volumes`), (3) placement/scheduling/event bus are tenant-blind (`domain.PlacementRequest:114` carries no tenant field; `eventstore/migration.go:19` has no tenant column).
* **Secrets/transport correctly surpasses references** where it matters: AES-256-GCM keyring with AAD (`secrets/keyring.go:75`), scrubbed cron env (`cronjob/service.go:212`), quoted DB identifiers (`dbprovisioner/service.go:737`), WebSocket ticket HMAC with single-use Redis Lua (`handlers_ws_ticket.go:159`), and WS origin validation distinguishing cookie vs bearer (`ws_origin.go:57`). Gaps are defense-in-depth: `fallback-nonce` + `strict-dynamic` (`middleware_security.go:22`), `X-Forwarded-Proto` trusted without CIDR gate (`middleware_mtls.go:123`), rate-limit `TrustedIPs` bypass combined with permissive `IsPrivate` peer check (`middleware_ratelimit.go:98`).
* **UX/Product IA mirrors the gateway fragmentation diagnosis** — 5 registry groups (62 entries) remapped to 6 goal groups in `admin-shell.tsx:42` via a `plan` href map that surfaces only ~50 entries; the previous `Recovery`→`/admin/migrations` duplicate is now fixed (single `Migrations` entry) but new invisible entries persist (`Kubernetes`/`Containers`/`Dev/States` routes without registry entries). App detail uses `useState` tabs not routes, deployment has two competing pollers, status tones are per-file, logs/metrics are duplicated, domains/TLS verification is gated behind a server selector, and three env-var editors diverge — all classic `Reference UX01-UX06` recurrences.
* **Product IA recommendation is the highest-leverage fix:** collapse 7 networking pages (`traffic`, `load-balancer`, `domains`, `certificates`, `security`, `firewall`, `endpoints`) into one declarative **Gateways** section (Routers/Services/Middlewares/Certs tabs) — the Traefik-shaped model proven in `phase-04/subagent-04-forge-gateway.md:113` — while unifying tenancy filtering, env-var editing, and audit trails.

### FORGE-LOGIC-S01 — Subuser `*` / Arbitrary Permission Escalation (P0, SECURITY)

**Locations:** `forge/api/internal/store/store_users.go:297` `UpsertServerSubuser`, `544` `normalizeSubuserPermissions`, `353` `UserCanAccessServer` (wildcard via `HasPermission`); `forge/api/internal/store/permissions.go:206` `HasPermission` (`p=="*"` wildcard); `forge/api/internal/http/handlers_servers.go:541` `POST /servers/:id/users` (`requireServerPermission(PermUserCreate)`), `574` `PATCH .../users/:id` (`PermUserUpdate`).

**Reference contract:** `reference/game-hosting/pterodactyl-panel/app/Models/Permission.php:120` ("never assign permissions they do not have themselves") + `SubuserController.php:154` `getDefaultPermissions` (intersect + inject `websocket.connect`, never store `*`).

**Defect:** `normalizeSubuserPermissions` allows `*` (`!allowed[perm] && perm!="*"` → keep) without actor-subset check. Any `user.create`/`user.update` holder can grant any allowlisted perm or `*` to any user. `HasPermission` then makes `*` universal (including `database.view_password`, `schedule.delete`, `allocation.delete`, `settings.reinstall`, `cron.create` which dispatches to node via `cronjob/service.go:240`). `CheckUserCanCreateSubuser` at `handlers_servers.go:541` only validates count limits, not subset.

**Evidence:**
```go
// store_users.go:552-554 — only allowlist, no actor-subset gate
if permission == "" || seen[permission] || (!allowed[permission] && permission != "*") { continue }
// handlers_servers.go:541 — gates create but not grant scope
if err := checkServerPermission(c, cfg, store.PermUserCreate); err != nil { return err }
subuser, err := cfg.DB.UpsertServerSubuser(c.Context(), serverID, req, actorID) // req.Permissions unchecked

**Impact:** Vertical privesc within a server.
