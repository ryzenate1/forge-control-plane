## 1. Executive Summary

Forge has **provisioning breadth** equal to 1Panel for DB engines and a **richer game-template authoring package** than PufferPanel's raw spec, but four structural gaps dominate:

1. **Depth gaps per-engine:** MySQL multi-host/user+grant lattice, PostgreSQL superuser/bind, MongoDB `dbOwner/read/readWrite/userAdmin` privilege selection, Redis `INFO`/`CONFIG GET/SET`/persistence tuning, and all `SHOW GLOBAL VARIABLES/STATUS`/`my.cnf` day-2 tuning are absent. Only binary `ALL` vs `SELECT` grants exist.
2. **Entire language-runtime layer missing by design:** 1Panel's `model.Runtime:9` + `model.PHPExtensions:3` (PHP-FPM, Node modules, supervisord, FPM FastCGI status, `install-ext` + `docker commit`) maps to nothing in Forge; `forge/api/internal/services/runtime/runtime.go:1` is a game-server runtime (Start/Stop/Stats/Logs) via docker/podman/k8s adapters — intentional product divergence.
3. **Catalog split-brain:** Forge fractures PufferPanel's single `templates/*.json + data.json + spec.json` model into **four disconnected catalogues** — (a) `packages/game-templates` (14 on branch, **deleted on disk** at audit time, still in HEAD), (b) `forge/web/lib/egg-templates.ts:1` (14 hardcoded constants), (c) DB `nests/eggs/egg_variables` (`store_nests.go:1` + `store_templates.go:1` compat shim, seeded to **1 egg** `091_seed_minecraft_java.sql:3`), (d) `store_catalog.go:1` (11 `catalog_entries`) + `store_app_store.go:1` (7 `app_store_apps`) + (e) `forge/web/lib/app-templates-data.ts:1` (5 defaults, `localStorage:forge.app-templates.v1`). No single source, no seeding job bridging FS → DB, no `Batch` upsert like `service/compose_template.go:58`.
4. **Logic bugs from duplicated provisioners:** `DBContainer.list` omits encrypted columns (LF01), `Deprovision`/`Restart` swallow daemon errors (LF02), MySQL TLS global map leak (LF03), root-vs-app password divergence (LF04), managed-delete status race (LF05), `validate-templates.mjs` placeholder blind spot (LF06).

Re-verification confirms prior audits; two evolutions: (a) `packages/game-templates` is currently **deleted from working tree** (unstaged deletion vs HEAD) — seeding deficit is now **100% on checkout**, not just on `main`; (b) `HANDOFF.md` now mandates **5-layer multiplication strategy** (`capabilityMatrix + featureFlags.slice + catalogEntries` precedent).

### LF03 — Global `mysql.RegisterTLSConfig` leak and race per host (P1, security)

**Location:** `forge/api/internal/services/dbprovisioner/service.go:373`

```go
name := mysqlTLSConfigName(host) // sha256(ID+host+mode+serverName+CA)[:12] at :418
```

`mysql.RegisterTLSConfig` mutates global `map[string]*tls.Config`; name derived from host attributes so each distinct host registers a new entry never unregistered nor updated if `tlsCA` rotates.
